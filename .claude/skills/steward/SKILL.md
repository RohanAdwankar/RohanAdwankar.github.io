# Pull requests in this repository

- Do not schedule recurring check-ins on a pull request. No hourly
  reminders, no self-wakeups, no polling. Open the PR, report it once,
  and stop.
- Do not subscribe the session to PR activity unless the owner asks.
- The owner merges when the result looks right to them. A green, open PR
  is finished work, not a task to keep watching.
- CI failures and review comments are handled when the owner brings the
  session back to the PR.
